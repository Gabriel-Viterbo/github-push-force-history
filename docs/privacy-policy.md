# Privacy Policy — GitHub Push Force History

**Last updated:** June 2026  
**Contact:** absolvertree@gmail.com

## What this add-on does

GitHub Push Force History is a browser extension that runs only on GitHub pull request pages (`https://github.com/*/*/pull/*`). It reads force-push events from the page you already opened and shows a side panel with links to GitHub compare views.

## Data collection

This add-on:

- does **not** collect, store, or transmit personal data to the developer or third-party servers;
- does **not** use the GitHub API or ask for GitHub tokens;
- does **not** include analytics or advertising;
- processes information **only locally** in your browser from the visible page content (DOM).

## Permissions

The extension manifest requests **no** optional permissions. It injects a content script only on GitHub PR URLs you visit.

## Changes

If this policy changes, the updated text will be published in the project repository.
